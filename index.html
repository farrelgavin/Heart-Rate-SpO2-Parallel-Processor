Program Python

Implementasi komputasi paralel menggunakan multiprocessing.Pool untuk memproses data kesehatan pasien secara bersamaan.

📦 Import Library
import multiprocessing
import time
import random
🔧 Fungsi Worker
def process_patient_data(patient_info):
    patient_id, hr_data, spo2_data = patient_info
    process_name = multiprocessing.current_process().name

    print(f"[{process_name}] Memproses Pasien {patient_id}...")
    time.sleep(1)  # Simulasi komputasi berat

    avg_hr   = sum(hr_data)   / len(hr_data)
    avg_spo2 = sum(spo2_data) / len(spo2_data)

    # Tentukan status kesehatan
    if   avg_hr < 60:  hr_status = "Bradikardia"
    elif avg_hr > 100: hr_status = "Takikardia"
    else:              hr_status = "Normal"

    spo2_status = "Normal" if avg_spo2 >= 95 else "Hipoksemia"

    return {
        "patient_id" : patient_id,
        "avg_hr"     : round(avg_hr, 2),
        "hr_status"  : hr_status,
        "avg_spo2"   : round(avg_spo2, 2),
        "spo2_status": spo2_status,
    }
⚡ Inti Komputasi Paralel
if __name__ == "__main__":
    # Bangkitkan data 4 pasien
    patients = [generate_patient_data(f"P{i+1:02d}") for i in range(4)]

    start_time = time.time()

    # Proses PARALEL — inti dari program ini
    with multiprocessing.Pool(processes=4) as pool:
        results = pool.map(process_patient_data, patients)

    end_time = time.time()

    for r in results:
        print(f"Pasien {r['patient_id']}: HR={r['avg_hr']} → {r['hr_status']}")
        print(f"               SpO2={r['avg_spo2']}% → {r['spo2_status']}")

Teori

Konsep Komputasi Paralel

Memahami cara kerja multiprocessing Python dan mengapa ia lebih unggul untuk tugas CPU-bound.

🔄 Alur Kerja Program
InputData 4 pasien (500 titik HR + SpO2 tiap pasien)
↓
Pool(4)Buat 4 worker process di core berbeda
↓
pool.map()Distribusikan tiap pasien ke worker secara PARALEL
↓
OutputRata-rata HR, SpO2, dan status kesehatan tiap pasien
⚖️ threading vs multiprocessing
Aspekthreadingmultiprocessing
Cocok untuk I/O-bound (file, network) CPU-bound komputasi berat
GIL Python Terkena tidak benar-benar paralel Bebas tiap proses punya GIL sendiri
Memori Shared — rawan race condition Terpisah per proses — aman
Overhead Rendah Lebih tinggi (spawn process)

Pemrosesan sinyal sensor adalah CPU-bound, sehingga multiprocessing adalah pilihan yang tepat.
